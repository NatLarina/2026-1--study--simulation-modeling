Слайд 2: Цель работы

  • Реализовать аналитическое и имитационное исследование M/M/c
  • Построить зависимость среднего времени ожидания от интенсивности входного потока
  • Проанализировать модель Росса:
    • влияние числа резервных машин (S) и ремонтников (R) на время до падения
    • динамику числа исправных машин
    • длину очереди на ремонт и загрузку ремонтников
  • Сравнить аналитические и симуляционные результаты

Слайд 3: Модель M/M/c – основные параметры

Параметр Обозначение Смысл
λ интенсивность входящего потока среднее число заявок в единицу времени
μ интенсивность обслуживания среднее число заявок, обслуживаемых одним каналом
c число каналов количество параллельных серверов
ρ = λ/(cμ) загрузка канала условие стационарности: ρ < 1

Формула Эрланга для вероятности ожидания:

[ P_{\text{wait}} = \frac{(c\rho)^c}{c!(1-\rho)} P_0, \quad W_q = \frac{L_q}{\lambda} ]

Слайд 4: График M/M/c (Wq vs λ)

При μ = 0.5, c = 2. При λ → 1.0 время ожидания резко возрастает.

Слайд 5: Модель Росса – постановка

  • N работающих машин, S резервных, R ремонтников
  • Время работы до отказа ~ Exp(λ), среднее 1/λ
  • Время ремонта ~ Exp(μ), среднее 1/μ
  • Если работающая машина ломается, её заменяет резервная (если есть)
  • Если резерва нет – система падает
  • Оценить среднее время до падения E[T]

Слайд 6: Влияние резерва и ремонтников

  • По оси X – число резервных машин S
  • По оси Y – среднее время до падения (логарифмическая шкала)
  • Три кривые – для R = 1, 2, 3 ремонтника
  • Вывод: увеличение S и R значительно увеличивает живучесть системы

Слайд 7: Динамика числа исправных машин

  • N = 10, S = 3, R = 1
  • Ступенчатый процесс: отказы (↓) и ремонты (↑)
  • Пока число исправных ≥ N – система работает
  • При падении ниже N – останов

Слайд 8: Очередь на ремонт (R = 2)

  • Длина очереди сломаных машин, ожидающих ремонт
  • Колеблется в зависимости от потока отказов
  • В моменты интенсивных отказов очередь растёт

Слайд 9: Загрузка ремонтников (R = 2)

  • Показывает, сколько из двух ремонтников заняты
  • Значения 0, 1, 2
  • Периоды полной загрузки и простоев

Слайд 10: Сравнение аналитики и симуляции

Слайд 11: Выводы

  1. M/M/c – классическая СМО, время ожидания резко растёт при загрузке → 1.
  2. Модель Росса демонстрирует:
    • резервирование (S) критически важно для предотвращения падения
    • увеличение числа ремонтников (R) повышает надёжность, но не так сильно, как рост S
    • динамика очереди на ремонт и загрузка ремонтников носят случайный характер
  3. Аналитические решения хорошо согласуются с имитационными экспериментами.
  4. Рекомендация: для систем с высокой интенсивностью отказов нужно создавать запас резервных машин, а не только увеличивать ремонтную бригаду.
